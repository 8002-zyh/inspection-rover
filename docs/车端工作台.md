# 车端工作台

工作台（`patrol.server`，端口 8765）与车端采集控制（`patrol.robot`，8766）都在小车上运行。
手机或其他电脑只要和车在同一网络，打开 `http://<车IP>:8765` 用 operator 账号登录即可。

- 车内互相访问用 `127.0.0.1`，对外绑定 `0.0.0.0`。
- 电脑不必一直在线；断网时事件仍存在车本地库。
- 启动：`sh start_car_workbench.sh`（默认硬件关闭）。
- 密钥仍在 `.local-access/`，勿提交 Git。

## 路线面板（登录后「现场巡检」）

- 开始录制 →（有硬件：先使能再按住前进，可同时按左/右）→ 结束录制并保存。
- 无硬件时为 dry-run：不必使能，方向键只记样本；回放只走时间轴，不发动力。
- 下拉选路线 → 回放；随时「停止路线」。
- Robot API（经工作台 `/api/robot/...` 代理）：`GET /routes`、`GET /routes/status`、`POST /routes/record/start|stop|note`、`POST /routes/play|stop`。

## 访问注意（2026-11-01）
- 必须用明文 `http://<车IP>:8765/`，不要写成 `https://`。
- 车 IP 随手机热点变化；用车屏 `hostname -I` 确认。
- 大灯可在工作台开关；双闪串口 TX 不支持。
- 心跳超时 = 浏览器未续控制租约；操作员停止 = 页面主动停/松手等。
