# 路线录制回放（最快演示路径）

更新：2026-10-31（Asia/Shanghai）。目标：场地里录一条短路线，再点一下自动沿原路径低速巡检；电脑不必一直连着车。

## 1. 选型结论

**采用「阿克曼指令时间轴」录制/回放（duty + steering），不做本阶段 FAST-LIO/NDT。**

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| FAST-LIO + 厂家 CSV 巡航 | 有地图、可重定位 | 车端 CSV/旧场地坐标缺失；外参与定位未验收；排障 >1 天 | **搁置** |
| 轮速/IMU 航迹推算航点 | 不依赖雷达建图 | Wit IMU/反馈未接入本仓库；累积漂移大 | 后续增强 |
| **指令时间轴回放** | 复用现有 Guard/租约/限速；半天可演示 | 只适合同一场地、近似同起点；打滑会偏 | **本阶段采用** |

厂家 `path_planning_cruise` / FAST-LIO 仍保留在车载 `~/Desktop/4pro`，不删；本原型不依赖它们。

## 2. 联网模型（回答「必须连电脑吗」）

**实际使用：车单独上网即可；工作台另机运行；巡检不要求 PC 一直在线。**

- 车端 `patrol.robot` 常驻：识别 → 本地 SQLite 缓存 → 能连上工作台再补传（已有 uploader）。
- 路线文件存在**车端** `runtime/robot/routes/*.json`。回放由车端 `RouteController` 自己持有租约、按时间轴喂 `Guard.command`，**不依赖浏览器心跳**。
- 工作台负责：选路线、启停、预览、看事件。离线时车仍可跑已选定路线（后续可加 `auto_route_id` 开机自启）；事件积压，恢复网络后补传。
- 演示时推荐同热点，方便启停与预览；不是硬性依赖。

## 3. 数据格式 `patrol.route.v1`

```json
{
  "schema": "patrol.route.v1",
  "id": "demo-short-01",
  "name": "场地短路线",
  "created_at": "2026-10-31T05:00:00+00:00",
  "sample_hz": 10,
  "max_duty": 0.03,
  "notes": "同一起点、平整路面",
  "samples": [
    {"t": 0.0, "duty": 0.03, "steering": 0},
    {"t": 0.1, "duty": 0.03, "steering": -40}
  ]
}
```

- `t`：相对起点秒；单调非降。
- `duty`：∈[0, 0.03]，禁止负值（无后向测距）。
- `steering`：相对中位的偏置（与现网页一致，单位与 Guard 相同）。
- 可选扩展（本骨架不强制）：`rpm`、`range_front` 仅作标注。

## 4. API

### 车端（8766，需 `X-Device-Token`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/routes` | 列表摘要 |
| GET | `/routes/status` | idle/recording/playing |
| POST | `/routes/record/start` | 开始录制；无硬件时进入 dry-run |
| POST | `/routes/record/stop` | 结束并落盘 |
| POST | `/routes/record/note` | dry-run 方向键采样（亦可在实录时补记） |
| POST | `/routes/play` | body:`{route_id}`；无硬件时 dry-run 走时间轴 |
| POST | `/routes/stop` | 停录制或回放并锁定 |

回放期间（有硬件）：`RouteController` 自持 lease，按样本 `command`，**样本间隙会重发上一帧保心跳**；仍受障碍停车 / HARD_MAX_DUTY / 禁止倒车约束。浏览器手动控制与路线回放互斥。无硬件：dry-run 只推进状态机，不 `enable`、不写串口。

### 工作台（8765，登录+CSRF）

经现有 `/api/robot/<path>` 代理上述路径。UI：路线下拉 + 命名 + 录制/回放/停止；可同时按住前进与左/右转向；无硬件时按钮仍可用（标注 dry-run）。

## 5. 安全

- `hardware_enabled` 默认 false；关闭时 record/play 为 dry-run（无运动）。开启后才真正使能底盘。
- `HARD_MAX_DUTY=0.03`；duty 钳制 ≥0。
- 失联：回放线程异常或停止 → `Guard.stop`；串口故障路径不变。
- 不与 Codex/他进程同时控车。

## 7. 与现码缺口（摘要）

工作台已接路线面板；无硬件 dry-run 可演练；有硬件时回放经 Guard 安全路径。实车运动仍需用户在场批准。
