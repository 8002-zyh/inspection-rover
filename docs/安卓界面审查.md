# Android 0.1.0 界面审查

范围：原生Java连接/工具栏 + WebView工作台，使用苹果设计的可读性、层级与分组原则；返回手势、状态栏、照片选择器保持Android行为。不是iOS合规认证。

设计意图：让操作员优先看现场、控制状态和任务结果。连接页只输入车IP；巡检页突出相机和方向控制；任务按状态分组。常驻原生红色停止按钮不随网页滚动或切页消失。

## 具体实现

- 字体：Android系统字体；原生大标题32sp，说明17sp，工具按钮15sp；网页大标题32px、卡片标题19px，正文14–16px，辅助信息12–13px。WebView按Android fontScale设置textZoom，不打包SF Pro或SF Symbols。
- 布局：24dp原生边距、8/16/24间距；连接表单放ScrollView避免键盘压缩后不可达；系统Insets留出状态栏和导航手势区；网页按可用宽度换列。
- 按钮：原生常用按钮48dp高，连接56dp；方向按钮76px高；次要筛选保留44px，后续可再按Material扩大。原生Ripple反馈，不加弹跳动效。
- 导航：底部只保留现场/异常/任务三个目的地，退出登录移到原生地址设置页；Android返回退出到连接页，不模拟iOS侧滑手势。
- 材质：内容卡片不透明；毛玻璃只用于浮动导航层，降低透明度偏好有实色回退；减少动态偏好会禁用过渡。
- 状态：连接、控制、待补传与检查点有文字；异常不能只靠红绿判断；AI结果保留人工确认与限制；技术信息折叠。
