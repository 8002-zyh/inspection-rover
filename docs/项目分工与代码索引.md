## 复现

Windows虚拟环境中执行 `python -m unittest discover -s tests -q`、`node tests/test_http_client.cjs` 和 `node tests/test_android_lifecycle.cjs`。构建与安装见[安卓APP](安卓APP.md)，车辆启动与限制见[车端工作台](车端工作台.md)及[HANDOFF](../HANDOFF.md)。自动测试不驱动实车，现场运动脚本必须按当次场地和监护条件执行。
